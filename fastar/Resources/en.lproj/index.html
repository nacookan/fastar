fastar Help

Star-rate large image sets, fast.

Basic Workflow

  • Open a folder to list the images inside it. All formats supported by macOS are recognized, including JPEG, PNG, RAW, HEIF, and TIFF.
  • Select an image from the thumbnail list to open it in the main viewer.
  • Use the Left and Right Arrow keys to move to the previous or next image.
  • Press 0 through 5 to set the current image rating.
  • Ratings are saved next to each image in a sidecar file with the same filename and the .fastar extension.
  • Use the thumbnail list controls to filter by rating and sort by name or timestamp.
  • Drag an image from Finder or the thumbnail list into the comparison pane to compare it with the main image.
  • Export copies of the images currently shown in the thumbnail list to another folder.
